# Portfolio — Ruhi Mohammed Anana

Static site (HTML, CSS, JavaScript). No build step.

- Open `index.html` in a browser, or host the folder on GitHub Pages, Netlify or Vercel.
- `css/style.css` styles, `js/script.js` certificate/resume viewer.
- `assets/` photos; `assets/docs/` certificate and resume images (mapped in `js/script.js`).
- Fonts load from Google Fonts, so an internet connection is needed for them.
